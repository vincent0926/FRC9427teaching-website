# FRC 9427 程式教學網站

給 FRC 9427 新成員的 Java 機器人程式課程，共 20 章。每章都有生活比喻、程式範例、常見錯誤、小測驗和練習，部分章節附互動實驗。

- 網站：https://vincent0926.github.io/FRC9427teaching-website/
- 原始檔（給其他 AI 或工具直接讀取）：https://raw.githubusercontent.com/vincent0926/FRC9427teaching-website/main/index.html

## 課程內容

| 部分 | 章節 |
|---|---|
| 準備 | 00 開發環境與專案結構 |
| Java 與物件導向 | 01 類別與物件、02 封裝與存取修飾詞、03 繼承與介面、04 Lambda 與方法參考、05 列舉、常數與套件 |
| 架構 | 06 IO 架構 |
| WPILib 基礎 | 07 機器人程式的生命週期、08 Subsystem 與 Command、09 Trigger 與按鍵綁定、10 組合指令 |
| 硬體 | 11 Phoenix 6 與 TalonFX、12 感測器與 CAN 除錯 |
| 控制 | 13 PID 與前饋、14 MotionMagic、15 SysId 系統鑑別 |
| 上場 | 16 自動階段與路徑、17 視覺與定位、18 模擬、日誌與重播、19 上場檢查與 Pit 除錯 |

內容依據 2026 賽季的 WPILib、CTRE Phoenix 6、PathPlanner、AdvantageKit 官方文件，每章最後附資料來源。
